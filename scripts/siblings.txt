# The sibling checkouts this module is built and tested against, each at ONE pinned commit.
#
# go.mod replaces each of them with ../<name> (and pion/sctp with ../connect/sctp), so a build here
# is a build against whatever those directories hold. This file is the record of which commits
# that was, and it is a file rather than a CI setting so that it holds without a CI service:
# urnetwork's repositories are built and tested on the maintainers' own hardware (connect
# e8611390), and a pin that lives only in a workflow goes when the workflow does.
#
# scripts/siblings.sh reads it. With a name it clones a missing sibling at its pin; with --verify
# it refuses a sibling at any other commit, or with modified tracked files, before anything is
# built; and either way it refuses an unpinned name, a short or symbolic commit, a fetch source
# that is neither https://github.com/urnetwork/ nor one of the review sources it lists, and a
# connect that still carries the messaging schema. .github/workflows/gates.yml runs both. The
# format is github.com/urnetwork/message's own scripts/siblings.txt, and so are the rules. Move a
# pin in a commit of its own.
# name  url  commit
#
# TWO OF THESE PINS ARE PULL REQUEST HEADS, FETCHED FROM THE OWNER'S FORKS UNTIL THEY MERGE. This
# module's switch is the fourth of a set: the removal of messaging from urnetwork/sdk, the removal
# from urnetwork/connect, the import into urnetwork/message, and this. They are built and tested
# together, so this file pins the heads of two of them, and those heads are on the forks the pull
# requests come from. The pin is the commit, which no fetch source can change. When a pull request
# has merged (with a merge commit, so its head keeps its id), switch that line's URL to the
# urnetwork repository named in its comment and delete the fork from scripts/siblings.sh's review
# sources; until then every run of the script prints FORK beside that sibling.
#
# message: github.com/urnetwork/message, where this module's record layer, its codec and its
# schema live since ledger 284. Pinned to the head of the message pull request: branch
# split/import-all of the fork. That repository pins this one in turn, because its acceptance suite
# and its loopback library run this server in process, and two commits cannot each name the other:
# it pins ee23a490, this branch before this pin was filled. From ee23a490 to the commit that filled
# this pin no Go file changes, nor go.mod, nor go.sum, so the server tested there is the one tested
# here. After the merge: https://github.com/urnetwork/message.git.
